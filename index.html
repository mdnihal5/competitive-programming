how to pull a card

Using a template

  1. Open a .cpp file, type normal, hit Tab — the base template.
  2. Type any trigger below (e.g. DSU, SegTree, BinaryLift) and Tab again.
  3. No snippets installed? Open the file in this repo and copy everything between SNIPPET START and SNIPPET END.
  4. Run tests/run_all.sh to compile and run every template's own stress test.

Triggers never redeclare all / int / mod / N / inf — they assume normal already ran. Every struct is self-contained, so two cards never collide when pasted together.
