Template Catalogue

48 pasteable C++ templates, indexed the way a contest actually finds them — by trigger, not by scrolling. Every entry is a struct with a test attached, not a snippet that happens to work once.

USAGEnormal mode
  1. Open a .cpp file, type normal, hit Tab — the base template.
  2. Type any trigger from a pane below (e.g. DSU, SegTree) and Tab again.
  3. Forgot a trigger? Type list, hit Tab — prints every trigger + description as a comment, read live from INDEX.md.
  4. No snippets? Open the file here, copy between SNIPPET START / END.
  5. Run tests/run_all.sh — compiles + runs every template's own stress test.

Triggers never redeclare all/int/mod/N/inf — every struct is self-contained, so cards never collide when pasted together. macOS: brew install gcc astyle once.
